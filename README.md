# THE WORLD BRAIN · WBR

The real intellectual lineage of world-government thought — from the Stoic *cosmopolis* (c. 300 BCE) to the AI-governance moment (2023–25). An interactive timeline that plots each thinker on a spectrum of authority (moral idea → federation → limited authority → single sovereign) and reveals that serious thought clusters in **Kant's federation band**, that the single-sovereign extreme is rare and expressly warned against, and that today's AI governance sits in the weakest, softest tier.

**Live:** https://davidwise01.github.io/the-world-brain/

16 nodes, all fact-checked. Named for H.G. Wells's *World Brain* — which was a knowledge network, **not** a government.
